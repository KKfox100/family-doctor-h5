# 家庭医生助手 · Family Doctor Assistant (H5)

一个基于**循证医学（Evidence-Based Medicine）**理念构建的移动端 H5 全科健康管理应用。知识库严格参考 **默沙东诊疗手册（MSD Manuals）**、**WHO**、**UpToDate** 及 **强生 / 辉瑞** 等国际权威药企临床指南，坚决剔除无科学依据的传统误区与偏方。

## 六大核心模块

| 模块 | 说明 |
|------|------|
| 疾病百科 | 24 个全科常见疾病结构化卡片：概述、典型症状、红旗预警信号、循证护理、科学辟谣、按通用名的用药指导 |
| 症状评估 | 三步结构化问诊，排查「红旗危险信号」，输出绿 / 黄 / 红三级分诊结论与可提供给医生的沟通摘要 |
| 科学辟谣 | 12 条高频误区辟谣（捂汗退烧、酒精擦浴、骨头汤补钙、红糖补血、大蒜治胃炎等） |
| 健康档案 | 多成员切换（本人 / 长辈 / 孩子），体温 / 血压 / 血糖趋势可视化，循证用药记录 |
| 急救用药 | 8 个急救指南（CPR、海姆立克、烧烫伤、止血、中暑、骨折、中毒、鼻出血）+ 10 类常用药通用名指南 + 儿童退热药剂量计算器 |
| 在线查询 | 本地库未涵盖的知识点，一键跳转默沙东手册 / UpToDate / WHO / PubMed / NHS / 梅奥诊所检索 |

## 技术栈

- 纯静态单页应用（单 HTML 文件，零构建依赖）
- Tailwind CSS + FontAwesome + Chart.js（均通过 CDN 引入）
- 响应式设计，适配手机浏览器与微信 H5 容器
- Clinical Blue × 医疗绿配色，专业、严谨、温馨

## 本地运行

直接双击 `index.html` 即可，或在仓库根目录启动任意静态服务器：

```bash
npx serve .
```

## 部署

本项目已部署至 Cloudflare Workers 静态资源。
